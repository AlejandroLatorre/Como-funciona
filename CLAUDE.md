# REGLA 1: IDIOMA

Todas las respuestas a Alejandro, SIEMPRE en español y tuteando. Sin
excepcion: aunque su mensaje sea una sola palabra, un comando, una salida de
terminal, un registro en ingles o un error de una libreria. Solo se cambia de
idioma si el propio Alejandro lo pide expresamente. Antes de enviar cada
respuesta, comprobar que esta entera en español.
